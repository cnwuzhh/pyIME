# 进展日志

本目录记录 pyIME 每次任务的实际进展，纳入版本控制。

## 记录约定

- 按北京时间（UTC+08:00）每日一个文件，命名为 `YYYY-MM-DD.md`。
- 每次任务结束时追加一条记录；同一天的多次进展放在同一文件中，按时间排序。
- 记录目标、完成事项、验证结果、阻塞项和下一步。失败或中断也要如实记录。
- 验证须区分“通过”“失败”“未执行”；未构建或未测试时不能宣称可运行。
- 补记历史进展时注明“补记”，不编造精确时间。
- 不覆盖历史记录，不写入凭据、密钥、用户词库或私人输入内容。
- 每次任务或阶段完成后，将本次相关改动和日志一起提交并主动推送；推送后核对远端提交。同步失败须记录原因，不将本地保存误写为远端已同步。

## 条目格式

```markdown
## HH:mm - 任务标题

- 目标：
- 完成：
- 验证：
- 阻塞：
- 下一步：
```
