# 安装包输出目录

以后产出的安装包统一放在本目录。

运行 [`scripts/build.ps1`](../scripts/build.ps1) 后，脚本会将上游生成的安装包复制到这里，核对 SHA-256，并输出最终路径。每次使用独立日期/时间构建号，保留各次构建，不再覆盖固定文件名。

安装包名形如 `星河输入法-0.17.4+20261104.083533-setup.exe`，完整版本为 `0.17.4+20261104.083533`。`latest-build.json` 记录最新包名、源码提交、SHA-256 和是否已推送构建 tag；每个包也有自己的 `.exe.build.json`，请一起保留。

从干净提交构建后自动推送 `build-YYYYMMDD-HHmmss` 注释 tag。开发脏工作区构建不会打 tag，不能作为已标记源码的正式交付。代码 tag 不等于 GitHub Release 附件已上传。

中文名为“星河输入法”，英文品牌为 `Stellar River`，完整英文产品名为 `Stellar River IME`。安装界面、Windows 输入法显示名、开始菜单和设置窗口均使用此品牌；已加入默认简体拼音、左右 Shift 中英文切换、白底横向 5 候选及蓝色选中圆角样式，尚未集成雾凇拼音所需的 Lua 插件。

首次安装默认勾选“简体拼音”“繁体拼音”“日语”，按此顺序排列，默认进入简体。英文通过 Shift 切换，不单独添加英文方案或 Windows 英语键盘；三个方案均支持 Shift 直输英文。已有用户自定义方案列表继续保留，不强制覆盖。

Alt+反引号按配置顺序循环三种方案，普通左右 Alt 都支持，AltGr / Ctrl+Alt 不触发；有未完成输入时先上屏原始字母，自定义列表按自己的顺序循环。单独 Shift 仍切换英文。不会修改 Windows 的 Alt+Shift 等系统热键；应用自身可能占用此组合。需要使用本次完整安装包升级运行时。

有候选时，逗号键 `,` 选择上一项、句号键 `.` 选择下一项；Page Up / Page Down 仍翻页。没有候选时保留普通标点，英文模式直输 ASCII 标点。

新安装默认父目录为 `Program Files\stellariver`，内部版本子目录保留；已有安装升级继续使用原目录，不自动搬移。安装器中的父目录选择仍可手动修改。

日语使用罗马字输入，支持平假名、片假名、汉字候选及日文标点。按 F4 选择“日语”；Enter 确认假名，空格或数字选择候选。首次部署需要编译日语大词库。安装目录包含日语来源声明和词库许可；此功能不运行 Mozc 引擎，不等同于其整句转换能力。

旧名 `weasel-0.17.4.0-installer.exe` 及未带日期的星河安装包属于此前的测试构建，请以 `latest-build.json` 中的日期版本为准。内部程序文件名及 TSF 标识保留上游兼容性，不影响显示名称。

运行 [`scripts/test-profile.ps1`](../scripts/test-profile.ps1) 可验证安装包中的配置及输入行为，并生成 `candidate-preview.png`；预览来自实际的原生 Weasel 候选窗，不是模拟图片。

安装包二进制仅保存在本地，不提交到 Git；本说明文件用于保留目录及其用途。
